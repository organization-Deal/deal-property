# DEAL! Website Workspace v5

## รอบนี้เปลี่ยนอะไร

หลังบ้านเดิมรวมโปรเจกต์และทุกข้อความไว้ในฟอร์มเดียว รอบนี้แยกตามงานจริง ไม่เปลี่ยนฐานข้อมูลผู้สนใจหรือการติดตั้ง Cloudflare เดิม

| เมนู | ใช้ทำอะไร |
| --- | --- |
| ภาพรวม | เริ่มงานจากทางลัด ดูฉบับร่างรอเผยแพร่และผลลัพธ์ 7 วัน |
| หน้าเว็บไซต์ | เลือกหน้า → ส่วน → ภาษา → แก้ข้อความหรือเปลี่ยนรูป พร้อมพรีวิวจากหน้าจริง |
| โปรเจกต์ | ค้นหา/กรองรายการ เข้าแก้ทีละโครงการ แยกข้อมูล รูป ราคา/สัดส่วน และสถานะ |
| คลังรูป | อัปโหลด ย่อไฟล์ เลือกรูปเดิม ใช้รูปซ้ำ และดูขนาดภาพ |
| ผู้สนใจโครงการ | ค้นหา ดูรายละเอียดและติดตาม Lead เดิม |
| สถิติผู้เข้าชม | แคมเปญ ประเทศ/พื้นที่ เซสชัน เส้นทางและ funnel เดิม |
| ประวัติเผยแพร่ | เรียกคืนเวอร์ชันเก่าเป็นร่างก่อนเผยแพร่ใหม่ |
| รูปแบบเว็บไซต์ | ระยะห่าง สีเน้น มุมการ์ด และขนาดข้อความหลักจากชุดรูปแบบที่กำหนด |

## วิธีแก้หน้าเว็บ

1. หน้าเว็บไซต์ → เลือกหน้าแรก, หน้า Rimping หรือส่วนร่วมทุกหน้า
2. เลือกส่วน เช่น ภาพเปิดหน้า รู้จัก DEAL! บริการ FAQ ผลงาน แปลน ทำเล หรือติดต่อ
3. เลือกภาษา ไทย/อังกฤษ/จีน แล้วแก้ช่องที่ต้องการ รูปใช้ร่วมทุกภาษา
4. กดบันทึกร่าง แถบตัวอย่างจะโหลดร่างที่บันทึกแล้วใหม่ สามารถเลือกจอคอมหรือมือถือ หรือเปิดเต็มหน้าได้
5. ตรวจทานและเผยแพร่ → อ่านสรุปการเปลี่ยนแปลงทั้งหมด → ยืนยันเผยแพร่

การบันทึกร่างยังไม่เปลี่ยนเว็บจริง การเผยแพร่เป็นการเผยแพร่ร่างทั้งชุด ไม่ใช่เฉพาะหน้าที่กำลังแก้ แถบตรวจทานจึงสรุปทุกหน้า ทุกภาษา รูป โปรเจกต์ และรูปแบบที่เปลี่ยน

ตัวอย่างใน iframe ต้องเปิดจากโดเมนเดียวกับหลังบ้านโดยมี session ผู้ดูแล เมื่อเข้าฉบับร่างจะมีแถบแจ้งและปิดการส่งฟอร์ม การนำทางภายในคงโหมดพรีวิวไว้ ไม่มีการใช้ข้อมูลสมมติแทนเว็บจริง

## ขอบเขตเนื้อหาที่แก้ได้

- 14 กลุ่มส่วนของหน้าจากแม่แบบเดิม ครอบคลุม 153 คีย์ข้อความและ 19 ช่องรูปที่ไม่ซ้ำ (บางข้อความ/รูปใช้ร่วมหลายตำแหน่ง)
- หน้าแรก: หัวเรื่อง/คำอธิบาย รูปหลัก รู้จัก DEAL! บริการสี่ขั้นตอน ผลงาน FAQ
- Rimping: คำอธิบายภาพเปิดหน้า สรุป การ์ด ทำเล แผนที่ แบบบ้านสี่มุม ข้อมูลตัดสินใจบางส่วน
- ส่วนร่วม: ข้อความติดต่อและท้ายเว็บ
- หน้าแรกจัดลำดับทั้ง 7 ส่วนและซ่อนส่วนได้ เมื่อซ่อน About/Care/FAQ ลิงก์ในเมนูและท้ายเว็บจะซ่อนตาม
- FAQ เพิ่ม/นำออก/เลื่อนคำถามได้สูงสุด30ข้อ แก้สามภาษาได้ ภาษาแปลที่ว่างใช้ไทยแทน หากยังไม่ปรับคอลเลกชันใหม่จะใช้7ข้อเดิม
- ช่องข้อความเป็น plain text ไม่รับ HTML/CSS สคริปต์ และไม่แก้รหัสเชื่อมต่อ

## โปรเจกต์

- เปิดมาที่รายการพร้อมค้นหาและกรองสถานะ ไม่ปะปนกับเนื้อหาทั้งเว็บ
- โปรเจกต์ใหม่เริ่มซ่อนและ Coming Soon ไม่สร้างข้อมูลทำเล/ภาพ/ผลตอบแทนสมมติ
- เข้าแก้ 4 แท็บ: ข้อมูล / รูป / ราคาและสัดส่วน / สถานะ
- แสดง checklist ข้อมูลที่ยังไม่ครบ กดรายการเพื่อไปส่วนที่ต้องแก้
- บันทึกโครงการที่เตรียมเปิดรับแต่ยังไม่ครบเป็นร่างได้ ระบบตรวจความพร้อมอีกครั้งก่อนเผยแพร่
- โครงการเปิดรับที่แสดงต้องมีราคา>0 เงื่อนไขไทย และสัดส่วนคงเหลือเพียงพอกับขั้นต่ำ
- ไม่มีการหักยอดจาก Lead อัตโนมัติ เพราะเป็นเพียงคำขอข้อมูล ไม่ใช่การชำระเงิน
- ID และ URL เดิมไม่เปลี่ยนเพื่อรักษาประวัติ
- Rimping เดิมแยกปุ่มจัดการสัดส่วน และมีทางลัดไปส่วนเนื้อหา Rimping
- ปุ่มสอบถามบนหน้าโปรเจกต์ใหม่จะเลื่อนไปฟอร์มโปรเจกต์นั้น ไม่เปิดฟอร์ม Rimping ผิดโครงการ

## คลังรูป

- เลือกรูปจากคลังได้ในตัวแก้หน้าเว็บและตัวแก้โปรเจกต์
- JPG/PNG/WebP ต้นฉบับสูงสุด40MB จะย่อด้านยาวไม่เกิน2000px แล้วบีบอัดไม่เกิน500KB ก่อนส่ง
- บันทึกภาพใหม่แบบ raster เพื่อตัด metadata ของภาพ ไม่มีการยกเลิกขีดจำกัดฝั่ง server
- HEIC ยังต้องแปลงเป็น JPG ก่อน
- มีรูปย่อ ขนาดไฟล์ ความกว้าง/สูง คัดลอกลิงก์ และแบ่งหน้า
- รูปเดิมอ้างอิงชื่อไฟล์ ส่วนรูปอัปโหลดไม่มีชื่อที่ตั้งเอง ค้นหาด้วยรหัสหรือชนิดไฟล์ ยังไม่มีระบบ tag/โฟลเดอร์/ลบไฟล์

## สิ่งที่ยังต้องใช้การพัฒนาเพิ่มเติม

v5 เป็น CMS บนแม่แบบที่มีขอบเขตชัดเจน ไม่ใช่ตัวสร้างทุกหน้าแบบลากองค์ประกอบอิสระ

- เพิ่มองค์ประกอบชนิดใหม่ เปลี่ยนโครงสร้างหน้าแบบอิสระ แก้ฟังก์ชันคำนวณ/สิทธิทางธุรกิจ
- ราคาเต็ม/ค่าบริหาร/ขั้นต่ำ/สูตรของ Rimping เดิมยังคงไว้ ส่วนนี้ยังไม่เปิดให้แก้จากหลังบ้าน (โปรเจกต์ใหม่แก้ราคาและสัดส่วนได้)
- ฟิลด์ฟอร์ม กฎ validation รายละเอียดกฎหมายและระบบหลังบ้านไม่ได้เปิดแก้ตามอำเภอใจ
- วิดีโอ โลโก้/ฟอนต์ ระบบ SEO metadata ระดับ server และการเพิ่มหน้าอิสระยังไม่อยู่ในตัวแก้นี้
- ไม่ได้เพิ่มบัญชีพนักงานและสิทธิแยกบทบาท ยังใช้ผู้ดูแลและรหัสเดิม ไม่สามารถระบุชื่อบุคคลที่เผยแพร่ได้จากประวัติที่มี

## ติดตั้ง

ZIP นี้เป็นอัปเดตสะสมสำหรับ repository เว็บบ้านเดิม รวม Lead/Analytics/เปอร์เซ็นต์/โปรเจกต์ v2-v4 แล้ว

1. ตรวจความต่างหากทีมอื่นแก้ repository ต่อจาก ZIP ก่อนหน้า
2. วางไฟล์ทับตามโฟลเดอร์ที่อยู่ใน ZIP ไม่ลบไฟล์เดิมที่ไม่ได้ส่งมา
3. Build/Deploy ตามระบบเดิม ไม่มี dependency, Database ID หรือ Cloudflare config ใหม่
4. เข้า /admin แล้วรีเฟรชเพื่อโหลด Workspace v5
5. ก่อนใช้งานจริง ตรวจร่างเก่า ดูตัวอย่างทุกหน้าที่ใช้งาน แล้วเผยแพร่เมื่อพร้อม

ข้อมูล CMS เก่าจะได้ค่าเริ่มต้นของส่วนใหม่อัตโนมัติ ไม่มี migration ใหม่สำหรับฟีเจอร์ v5

## ผลตรวจ

- TypeScript ผ่าน
- Production build ผ่าน
- Integration tests actual API handlers + SQLite ทดสอบผ่าน รวม auth, draft isolation, revision conflict, publish readiness, project Lead, สัดส่วน, media pagination/search, CMS text/image/layout/appearance, FAQ collection และสรุปการเปลี่ยนแปลง
- ยืนยันว่าค่า FAQ เริ่มต้นจับคู่ตรงกับ Q/A จริงทั้ง7คู่
- พรีวิว daemon เริ่มได้ แต่ cloud browser เปิด URL แล้ว ERR_CONNECTION_REFUSED จึงยังไม่ได้ตรวจหน้าจริงที่390/768/1280/1440, การย่อรูปผ่านcanvas, Safari หรือ iframe ใน production
- ยังไม่ได้อัป GitHub, Deploy หรือเขียนข้อมูล production D1

ก่อนนำไปใช้กับทีม ให้ทดสอบผู้ใช้จริง: เปลี่ยนภาพหน้าแรกหนึ่งรูป / เปลี่ยนFAQหนึ่งข้อ / เพิ่มComing Soonหนึ่งโปรเจกต์ / บันทึกร่างและตรวจทานเผยแพร่ โดยไม่เปิดโค้ด
