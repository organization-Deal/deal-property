วิธีใช้
/admin > จัดการโปรเจกต์ > เพิ่มโปรเจกต์
1. เลือกโปรเจกต์แล้วใส่ชื่อ ทำเล รูป รายละเอียด และสิทธิ/ค่าใช้จ่าย/เงื่อนไข
2. ภาษาไทยเป็นฐาน เพิ่มอังกฤษ/จีนได้ ถ้าว่างจะแสดงไทยแทน
3. เลือกสถานะ Coming Soon!, เปิดให้เป็นเจ้าของ, พักเปิดรับ หรือดำเนินงานแล้ว
4. เลือกแสดงเมื่อเผยแพร่ (โปรเจกต์ใหม่ซ่อนไว้เป็นค่าเริ่มต้น)
5. บันทึกฉบับร่าง > พรีวิวรายละเอียดที่บันทึก > เผยแพร่
Coming Soon ไม่แสดงราคา/ฟอร์มรับเป็นเจ้าของ
เปิดรับต้องมีราคา เงื่อนไข และยอดเหลือเพียงพอกับขั้นต่ำ (อย่างน้อย10%)
จัดลำดับด้วยปุ่มเลื่อนขึ้น สูงสุด50โปรเจกต์ใหม่
โปรเจกต์ใหม่ได้ ID และ URL อัตโนมัติ URL ล็อกหลังบันทึกเพื่อรักษาลิงก์เดิม
ไม่ลบข้อมูลโปรเจกต์ ให้ซ่อนหรือพักเปิดรับเพื่อเก็บ Lead อ้างอิงเดิม
สัดส่วนไม่หักอัตโนมัติจากการส่งฟอร์ม เพราะยังไม่ใช่การจองหรือชำระเงิน

หน้าบ้าน
การ์ดขึ้นทั้งหน้าแรกและหน้า /projects
แต่ละโปรเจกต์มีหน้า /projects/project-xxxxxxxx พร้อมรายละเอียดและฟอร์มเฉพาะเมื่อเปิดรับ
ราคาและวงเงินคำนวณจากข้อมูลที่เผยแพร่จริง API ตรวจสถานะ ราคา ขั้นต่ำและยอดเหลือ
Lead บันทึก Project ID และชื่อโครงการ/ราคาขณะส่งลงข้อความใน D1 เดิม
ภาพว่างเป็น placeholder ไอคอน ไม่ใส่ภาพโครงการหรือข้อมูลสมมติ
Rimping เดิมคงหน้า URL ราคาและฟอร์มเดิม จัดการเปอร์เซ็นต์ในส่วน Rimping เช่นเดิม
Coming Soon ตัวอย่างเดิมถูกแทนด้วยรายการที่ผู้ดูแลสร้าง ไม่สร้างโครงการปลอมให้อัตโนมัติ

ข้อมูลจัดเก็บใน site_content เดิม ใช้ระบบ draft/revision/publish/history ร่วมกัน
ไม่มี migration ใหม่สำหรับรายการโปรเจกต์ ข้อมูลเก่าอ่านได้
